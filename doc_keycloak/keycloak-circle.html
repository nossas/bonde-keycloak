Arquitetura Geral

A combinação de Keycloak e Circle.so forma uma plataforma completa onde o Keycloak é a central de identidade e o Circle.so é o núcleo da comunidade e dos cursos. O usuário só existe em um lugar: o Keycloak. O Circle.so é apenas um cliente SSO.

02

SSO Circle.so + Keycloak

O Circle.so implementa SSO via OAuth 2.0 customizado. Você fornece três endpoints do Keycloak e configura os campos que o Circle deve ler do userinfo. A partir daí, o Keycloak é o único responsável por autenticar o usuário.

Configuração mínima no Circle.so

CampoValor (Keycloak)
Authorization URL/realms/{realm}/protocol/openid-connect/auth
Token Fetch URL/realms/{realm}/protocol/openid-connect/token
User Info URL/realms/{realm}/protocol/openid-connect/userinfo
SSO ID pathsub
Email pathemail
Name pathname
Avatar pathpicture
⚠️
Plano necessário

SSO customizado e Circle API (incluindo Headless) estão disponíveis apenas nos planos Business e Enterprise do Circle.so.

03

Keycloakify + React

O Keycloakify compila um projeto React em um arquivo .jar que o Keycloak carrega como tema. Você tem controle total sobre cada página de autenticação usando componentes React, hooks, TypeScript e qualquer biblioteca de UI.

Setup do projeto

# Clonar o starter oficial
git clone https://github.com/keycloakify/keycloakify-starter.git
cd keycloakify-starter
yarn install

# Adicionar Storybook para desenvolvimento com hot-reload
# (sem precisar de Keycloak rodando localmente)
npx keycloakify add-story   # selecione: login.tsx
npx keycloakify add-story   # selecione: register.tsx
npm run storybook

# Build do tema (.jar)
npm run build-keycloak-theme

npx keycloakify eject-page
# Selecione: UserProfileFormFields.tsx
// src/login/pages/UserProfileFormFields.tsx
// Renderização customizada para cada tipo de campo

import { useFormContext } from "keycloakify/login";

export function UserProfileFormFields({ kcContext, i18n }) {
  const { profile } = kcContext;
  const { register, watch } = useFormContext();

  return (
    <>
      {profile.attributes.map(attr => {
        const type = attr.annotations?.inputType;

        /* ── SELECT com opções ── */
        if (type === "select") return (
          <div key={attr.name} className="field-group">
            <label className="field-label">{attr.displayName}</label>
            <select {...register(attr.name)} className="field-select">
              <option value="">Selecione...</option>
              {attr.validators?.options?.options?.map(opt => (
                <option key={opt} value={opt}>{opt}</option>
              ))}
            </select>
          </div>
        );

        /* ── MULTISELECT com checkboxes visuais ── */
        if (type === "multiselect") return (
          <div key={attr.name} className="field-group">
            <label className="field-label">{attr.displayName}</label>
            <div className="checkbox-grid">
              {attr.validators?.options?.options?.map(opt => (
                <label key={opt} className=`checkbox-item ${watch(attr.name)?.includes(opt) ? 'active' : ''}`>
                  <input type="checkbox" value={opt} {...register(attr.name)} />
                  {opt}
                </label>
              ))}
            </div>
          </div>
        );

        /* ── TEXTO padrão ── */
        return (
          <div key={attr.name} className="field-group">
            <label className="field-label">{attr.displayName}</label>
            <input
              {...register(attr.name)}
              className="field-input"
              placeholder={attr.annotations?.placeholder}
            />
          </div>
        );
      })}
    </>
  );
}
💡
Campos visíveis só para certos roles

Use o campo permissions.view e permissions.edit no User Profile para controlar quais campos aparecem para usuários, admins, ou apenas internamente. Isso permite ter campos internos (plano, score) que nunca aparecem no formulário público.

Account Console — O que é possível

O Account Console é o portal onde o usuário gerencia sua conta no Keycloak: senha, sessões ativas, autenticadores, etc. Desde 2024, o Keycloak disponibilizou o pacote @keycloak/keycloak-account-ui que permite construir do zero um Account Console customizado em React.

✨
O que você pode fazer com o Account Console customizado

Adicionar abas completamente novas com qualquer funcionalidade — consumindo APIs externas, como o Circle.so. Remover páginas que não fazem sentido para seu produto. Substituir páginas existentes por versões customizadas. Mudar layout, cores, logo e identidade visual. Tudo isso sem fazer fork do código-fonte do Keycloak.

Aba: Meus Cursos

Esta aba exibe os cursos que o usuário está inscrito no Circle.so, com progresso, último acesso e botão para continuar. Os dados vêm da Circle Headless API autenticada com o JWT gerado a partir do sub do Keycloak.

api/circle.ts — funções reutilizáveis

// src/api/circle.ts
// Funções para comunicar com a Circle.so API

const CIRCLE_API = "https://app.circle.so";
const HEADLESS_AUTH_TOKEN = import.meta.env.VITE_CIRCLE_AUTH_TOKEN;

/**
 * Obtém o JWT do Circle.so a partir do SSO ID do Keycloak.
 * Deve ser chamado server-side ou em um BFF.
 * O `sso_id` é o `sub` do token Keycloak do usuário.
 */
export async function getCircleJwt(ssoId: string): Promise<string> {
  const res = await fetch(`${CIRCLE_API}/api/v1/headless/auth_token`, {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${HEADLESS_AUTH_TOKEN}`,
      "Content-Type": "application/json"
    },
    body: JSON.stringify({ sso_id: ssoId })
  });
  const data = await res.json();
  return data.access_token;
}

/** Lista os spaces/cursos que o membro tem acesso */
export async function getMemberCourses(jwt: string) {
  const res = await fetch(`${CIRCLE_API}/api/headless/v1/spaces?type=course`, {
    headers: { "Authorization": `Bearer ${jwt}` }
  });
  return res.json();  // lista de spaces do tipo curso
}

/** Progresso do membro em um curso (lições concluídas) */
export async function getCourseProgress(jwt: string, spaceId: number) {
  const res = await fetch(
    `${CIRCLE_API}/api/headless/v1/spaces/${spaceId}/course_lessons`,
    { headers: { "Authorization": `Bearer ${jwt}` } }
  );
  return res.json();
}

/** Feed da comunidade (posts recentes nos spaces do membro) */
export async function getCommunityFeed(jwt: string, page = 1) {
  const res = await fetch(
    `${CIRCLE_API}/api/headless/v1/home?page=${page}&per_page=20&sort=latest`,
    { headers: { "Authorization": `Bearer ${jwt}` } }
  );
  return res.json();
}

/** Notificações não lidas do membro */
export async function getNotifications(jwt: string) {
  const res = await fetch(
    `${CIRCLE_API}/api/headless/v1/notifications?unread=true`,
    { headers: { "Authorization": `Bearer ${jwt}` } }
  );
  return res.json();
}

MeusCursos.tsx — componente completo

// src/MeusCursos.tsx
import { useState, useEffect } from "react";
import { Page, useEnvironment, usePromise } from "@keycloak/keycloak-account-ui";
import { getMemberCourses, getCourseProgress } from "./api/circle";

type Course = {
  id: number;
  name: string;
  slug: string;
  cover_image_url: string;
  description: string;
  totalLessons: number;
  completedLessons: number;
};

export function MeusCursos() {
  const env = useEnvironment();
  const [courses, setCourses] = useState<Course[]>([]);
  const [loading, setLoading] = useState(true);

  const circleJwt = env.features?.circleJwt; // JWT passado via environment

  useEffect(() => {
    if (!circleJwt) return;
    getMemberCourses(circleJwt).then(async (spaces) => {
      const withProgress = await Promise.all(
        spaces.map(async (s: any) => {
          const lessons = await getCourseProgress(circleJwt, s.id);
          return {
            ...s,
            totalLessons: lessons.length,
            completedLessons: lessons.filter((l: any) => l.completed).length
          };
        })
      );
      setCourses(withProgress);
      setLoading(false);
    });
  }, [circleJwt]);

  return (
    <Page
      title="Meus Cursos"
      description="Acompanhe seu progresso nos cursos da plataforma"
    >
      {loading ? (
        <div className="pf-v5-l-flex pf-m-justify-content-center">
          <span className="pf-v5-c-spinner" />
        </div>
      ) : (
        <div className="courses-grid">
          {courses.map(course => (
            <div key={course.id} className="course-card">

              /* Capa do curso */
              <div
                className="course-cover"
                style={{ backgroundImage: `url(${course.cover_image_url})` }}
              />

              <div className="course-body">
                <h3>{course.name}</h3>
                <p>{course.description}</p>

                /* Barra de progresso */
                <div className="progress-bar">
                  <div className="pf-v5-c-progress">
                    <div
                      className="pf-v5-c-progress__bar"
                      style={{
                        width: `${(course.completedLessons / course.totalLessons) * 100}%`
                      }}
                    />
                  </div>
                  <span>{course.completedLessons}/{course.totalLessons} aulas concluídas</span>
                </div>

                /* Botão de acesso */
                <a
                  href=`https://sua-comunidade.circle.so/c/${course.slug}`
                  target="_blank"
                  className="pf-v5-c-button pf-m-primary"
                >
                  {course.completedLessons === 0
                    ? "Começar curso"
                    : course.completedLessons === course.totalLessons
                      ? "✓ Concluído"
                      : "Continuar"}
                </a>
              </div>
            </div>
          ))}
        </div>
      )}
    </Page>
  );
}

Aba: Assinatura e Plano

Esta aba mostra o plano atual do usuário (armazenado como atributo no Keycloak) e permite trocar de plano. A mudança de plano dispara a sincronização no Circle.so via Admin API para ajustar o acesso aos Spaces.

// src/MinhaAssinatura.tsx
import { useState, useEffect } from "react";
import {
  Page, useEnvironment, useAlerts,
  AccountEnvironment
} from "@keycloak/keycloak-account-ui";

const PLANOS = [
  { id: "free",       label: "Gratuito",   preco: "R$ 0/mês",    recursos: ["Acesso básico", "Fórum geral"] },
  { id: "basic",      label: "Básico",      preco: "R$ 49/mês",   recursos: ["2 cursos", "Fórum geral", "Live mensal"] },
  { id: "premium",    label: "Premium",    preco: "R$ 99/mês",   recursos: ["Todos os cursos", "Mentoria", "Lives ilimitadas"] },
  { id: "enterprise", label: "Enterprise", preco: "Sob consulta", recursos: ["Tudo + whitelabel", "Suporte dedicado"] },
];

export function MinhaAssinatura() {
  const env = useEnvironment<AccountEnvironment>();
  const { addAlert } = useAlerts();
  const [planoAtual, setPlanoAtual] = useState("free");
  const [salvando, setSalvando] = useState(false);

  // Lê plano atual do atributo do usuário no Keycloak
  useEffect(() => {
    const plano = env.profile?.attributes?.plan?.[0] ?? "free";
    setPlanoAtual(plano);
  }, [env]);

  const handleMudarPlano = async (novoPlano: string) => {
    setSalvando(true);
    try {
      // 1. Atualiza atributo no Keycloak via Account API
      await fetch(`${env.serverBaseUrl}/realms/${env.realm}/account`, {
        method: "POST",
        headers: {
          "Authorization": `Bearer ${env.keycloakService.token}`,
          "Content-Type": "application/json"
        },
        body: JSON.stringify({
          attributes: { plan: [novoPlano] }
        })
      });

      // 2. Chama BFF para sincronizar spaces no Circle.so
      await fetch("/api/sync-circle-plan", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({
          ssoId: env.profile?.id,
          plano: novoPlano
        })
      });

      setPlanoAtual(novoPlano);
      addAlert("Plano atualizado com sucesso! ✓", "success");
    } catch (e) {
      addAlert("Erro ao atualizar plano. Tente novamente.", "danger");
    } finally {
      setSalvando(false);
    }
  };

  return (
    <Page title="Minha Assinatura" description="Gerencie seu plano de acesso">
      <div className="plans-grid">
        {PLANOS.map(plano => (
          <div
            key={plano.id}
            className=`plan-card ${planoAtual === plano.id ? 'active' : ''}`
            onClick={() => handleMudarPlano(plano.id)}
          >
            <div className="plan-name">{plano.label}</div>
            <div className="plan-price">{plano.preco}</div>
            <ul>{plano.recursos.map(r => <li key={r}>{r}</li>)}</ul>
            {planoAtual === plano.id && <span className="badge-ativo">Plano atual</span>}
          </div>
        ))}
      </div>
    </Page>
  );
}

BFF: sincronizar spaces no Circle.so ao mudar plano

// server/sync-circle-plan.ts (Node.js / Next.js API Route)
const SPACE_IDS_BY_PLAN: Record<string, number[]> = {
  free:       [111],               // Space: Comunidade Geral
  basic:      [111, 222, 333],     // + 2 cursos básicos
  premium:    [111, 222, 333, 444, 555], // todos os cursos
  enterprise: [111, 222, 333, 444, 555, 666]
};

export async function syncCirclePlan(ssoId: string, novoPlano: string) {
  const ALL_SPACES = [111, 222, 333, 444, 555, 666];
  const targetSpaces = SPACE_IDS_BY_PLAN[novoPlano] ?? [];

  for (const spaceId of ALL_SPACES) {
    const shouldHaveAccess = targetSpaces.includes(spaceId);
    const method = shouldHaveAccess ? "POST" : "DELETE";

    await fetch(`https://app.circle.so/api/v1/space_members`, {
      method,
      headers: {
        "Authorization": `Bearer ${process.env.CIRCLE_API_TOKEN}`,
        "Content-Type": "application/json"
      },
      body: JSON.stringify({ space_id: spaceId, sso_id: ssoId })
    });
  }
}

Aba: Meu Progresso

Consolida dados de atividade do membro no Circle.so — aulas concluídas, posts criados, comentários, reações recebidas — formando um painel de progresso gamificado.

// src/MeuProgresso.tsx
import { Page, useEnvironment } from "@keycloak/keycloak-account-ui";
import { useState, useEffect } from "react";

export function MeuProgresso() {
  const env = useEnvironment();
  const [stats, setStats] = useState(null);
  const jwt = env.features?.circleJwt;

  useEffect(() => {
    if (!jwt) return;
    // Busca estatísticas do membro via Circle Headless API
    Promise.all([
      fetch(`https://app.circle.so/api/headless/v1/posts?author=me`,
            { headers: { Authorization: `Bearer ${jwt}` } }),
      fetch(`https://app.circle.so/api/headless/v1/comments?author=me`,
            { headers: { Authorization: `Bearer ${jwt}` } }),
    ]).then(async ([postsRes, commentsRes]) => {
      const posts    = await postsRes.json();
      const comments = await commentsRes.json();
      setStats({
        posts:    posts.total_count ?? posts.length,
        comments: comments.total_count ?? comments.length,
        // outros dados: aulas concluídas, reações recebidas, streak...
      });
    });
  }, [jwt]);

  if (!stats) return <Page title="Meu Progresso"><span className="pf-v5-c-spinner"/></Page>;

  return (
    <Page title="Meu Progresso" description="Sua atividade na comunidade">
      <div className="stats-grid">
        <StatCard icon="📝" label="Posts criados"    value={stats.posts} />
        <StatCard icon="💬" label="Comentários"      value={stats.comments} />
        <StatCard icon="🎓" label="Aulas concluídas" value={stats.lessons ?? 0} />
        <StatCard icon="🔥" label="Streak (dias)"    value={stats.streak ?? 0} />
      </div>
    </Page>
  );
}

function StatCard({ icon, label, value }) {
  return (
    <div className="pf-v5-c-card">
      <div className="pf-v5-c-card__body stat-body">
        <span className="stat-icon">{icon}</span>
        <span className="stat-value">{value}</span>
        <span className="stat-label">{label}</span>
      </div>
    </div>
  );
}

Aba: Notificações

Exibe notificações não lidas da comunidade Circle.so diretamente dentro do Account Console. O usuário pode ver e marcar como lidas sem precisar acessar o Circle.so.

// src/MinhasNotificacoes.tsx
import { Page, useEnvironment, useAlerts } from "@keycloak/keycloak-account-ui";
import { useState, useEffect } from "react";

export function MinhasNotificacoes() {
  const env = useEnvironment();
  const { addAlert } = useAlerts();
  const [notifs, setNotifs] = useState([]);
  const jwt = env.features?.circleJwt;

  useEffect(() => {
    if (!jwt) return;
    fetch(`https://app.circle.so/api/headless/v1/notifications`, {
      headers: { Authorization: `Bearer ${jwt}` }
    }).then(r => r.json()).then(setNotifs);
  }, [jwt]);

  const marcarComoLida = async (notifId: number) => {
    await fetch(
      `https://app.circle.so/api/headless/v1/notifications/${notifId}/read`,
      { method: "PUT", headers: { Authorization: `Bearer ${jwt}` } }
    );
    setNotifs(prev => prev.filter((n: any) => n.id !== notifId));
    addAlert("Marcada como lida", "success");
  };

  return (
    <Page title="Notificações" description=`${notifs.length} não lidas`>
      {notifs.length === 0
        ? <p>Você está em dia! Nenhuma notificação pendente.</p>
        : notifs.map((n: any) => (
            <div key={n.id} className="pf-v5-c-notification-drawer__list-item">
              <div className="notif-content">
                <strong>{n.body}</strong>
                <span className="notif-time">{n.created_at}</span>
              </div>
              <button
                className="pf-v5-c-button pf-m-plain"
                onClick={() => marcarComoLida(n.id)}
                title="Marcar como lida"
              >✓</button>
            </div>
          ))
      }
    </Page>
  );
}

Circle.so — Mapa de APIs

O Circle.so possui três APIs distintas com propósitos diferentes. Entender qual usar em cada caso é essencial para construir integrações robustas.

Admin API v2 API Token (admin) Gerenciar membros, spaces, posts — operações administrativas server-side Business+
Headless Auth API Auth Token (admin) Gerar JWT do membro a partir de email, ID ou SSO ID — ponte Keycloak ↔ Circle Business+
Headless Member API JWT do membro Ações em nome do membro: posts, comentários, notificações, feed, cursos, chat Business+

Ponte Keycloak ↔ Circle.so

O sub do Keycloak (SSO ID) é a chave que liga as duas plataformas. Sempre que precisar agir no Circle.so em nome de um usuário do Keycloak, use esse fluxo:

1
Usuário autentica no Keycloak → você recebe o sub do access token
↓
2
Backend chama POST /api/v1/headless/auth_token com sso_id: sub
↓
3
Circle.so retorna access_token e refresh_token do membro
↓
4
Use o access_token para qualquer chamada da Headless Member API
// Exemplo completo: BFF que expõe dados do Circle.so ao Account Console
import jwt from "jsonwebtoken";

app.get("/api/circle/feed", async (req, res) => {
  // 1. Valida o token Keycloak do usuário
  const keycloakToken = req.headers.authorization?.split(" ")[1];
  const decoded = jwt.decode(keycloakToken) as any;
  const ssoId = decoded?.sub;

  // 2. Obtém JWT do Circle para esse usuário
  const authRes = await fetch("https://app.circle.so/api/v1/headless/auth_token", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.CIRCLE_AUTH_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ sso_id: ssoId }),
  });
  const { access_token } = await authRes.json();

  // 3. Chama Circle Headless API com o JWT do membro
  const feedRes = await fetch(
    "https://app.circle.so/api/headless/v1/home?per_page=20&sort=latest",
    { headers: { "Authorization": `Bearer ${access_token}` } }
  );
  const feed = await feedRes.json();

  res.json(feed);
});

Ideias para a Plataforma de Cursos

Abaixo estão possibilidades concretas que a combinação das duas plataformas permite construir — coisas que as documentações oficiais não contam diretamente.

🎮 Gamificação com XP e Níveis DESTAQUE

Use User Attributes do Keycloak para armazenar xp, level e streak de cada usuário. A cada aula concluída no Circle.so (via webhook), um serviço incrementa o XP do usuário no Keycloak. O Account Console exibe a barra de XP, nível atual e conquistas desbloqueadas. Roles do Keycloak podem ser automaticamente concedidas conforme o nível sobe (level_bronze, level_silver, level_gold), liberando novos spaces premium no Circle.so.

🎓 Certificados automáticos ao completar curso AUTOMAÇÃO

Configure um Keycloak Event Listener que é disparado quando o atributo course_123_completed de um usuário muda para true (atualizado via Circle API ao completar todas as lições). O listener chama um serviço que gera um PDF de certificado personalizado e envia por e-mail. O Account Console exibe todos os certificados disponíveis para download na aba "Meus Certificados".

🔓 Acesso progressivo por conquistas

Spaces no Circle.so são liberados automaticamente conforme o usuário avança. Ao completar o Módulo 1, o Keycloak recebe o role modulo_1_completo via API, e um serviço automaticamente adiciona o membro ao Space do Módulo 2. O usuário experimenta uma plataforma que se "abre" conforme ele avança — sem configuração manual.

📊 Dashboard de engajamento no Account Console

A aba "Meu Progresso" vai além de aulas concluídas: consolida posts criados, comentários feitos, reações recebidas, eventos assistidos e streak de login (calculado via Keycloak Event Log). Um gráfico de barras mostra a atividade semanal. Usuários top-engajados recebem automaticamente o role comunidade_ativo que dá acesso a um Space VIP.

🔔 Central de notificações unificada UX

O Account Console vira a central de comunicação do usuário. Notificações do Circle.so (novos posts, comentários, menções), e-mails enviados pelo Keycloak e alertas da plataforma aparecem em um único feed. O usuário marca como lido via Headless API sem precisar acessar o Circle.so diretamente.

🎨 Onboarding guiado no registro

O formulário de registro (Keycloakify) é transformado em um wizard multi-etapa: etapa 1 são dados básicos, etapa 2 são áreas de interesse (multiselect), etapa 3 é a escolha de plano. Com base nas respostas, o backend configura automaticamente os Spaces iniciais do usuário no Circle.so via Admin API — experiência de onboarding completamente personalizada desde o primeiro acesso.

👥 Matching de mentores e alunos

Usuários com o role mentor no Keycloak aparecem em uma aba "Encontre um Mentor" no Account Console, com perfis carregados via Circle Members API (foto, bio, especialidades). O aluno solicita mentoria via um post no Circle.so criado pela Headless API. O mentor aceita e ambos são adicionados a um Space privado de mentoria criado automaticamente via Admin API.

📅 Agenda de lives integrada

O Account Console exibe os próximos eventos do Circle.so via /api/headless/v1/events, com RSVP diretamente pelo portal. Ao confirmar presença, o usuário recebe um convite de calendário via e-mail disparado pelo Keycloak (custom Email Theme). Eventos passados ficam disponíveis como replay com link direto para o Space.

🔐 Login social com contexto de curso

A página de login do Keycloak detecta o parâmetro ?redirect_to=curso-xyz na URL e exibe uma mensagem contextual: "Faça login para continuar o Curso de React". Após autenticar, o usuário é redirecionado diretamente para o Space do curso no Circle.so, não para a home da comunidade. Implementado em Login.tsx lendo os parâmetros de query do contexto Keycloakify.

🚫
Nunca exponha tokens no frontend

O CIRCLE_AUTH_TOKEN (Headless Auth) e o CIRCLE_API_TOKEN (Admin API) são tokens server-side. Jamais os inclua em código que roda no browser. Use sempre um BFF (Backend For Frontend) para intermediar as chamadas ao Circle.so a partir do Account Console.
